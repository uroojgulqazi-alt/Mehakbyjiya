Delivery & Ordering Information

Pakistan-Wide Shipping

We deliver non-perishable custom gifts, jewellery, jhumky, acrylic LED frames, and explosion boxes across all cities in Pakistan through reliable express couriers.

Fresh Rose Arrangements

To preserve floral freshness, fresh rose bouquets and fresh floral gift boxes are strictly limited to hand-delivery in Islamabad & Rawalpindi only.

7 - 10 Days Advance Order

Because each piece is crafted with delicate handwork and custom personalization, orders should preferably be placed 7–10 days prior to your occasion date.

WhatsApp Confirmation

Delivery charges may vary based on package dimensions and delivery location. Final details and delivery dates are confirmed directly over WhatsApp conversation.

Store Setup & Developer README

Instructions for MehakByJiya Website Customization

1. How to Update the WhatsApp Number

At the top of the JavaScript code inside this file, locate the variable declaration:

const WHATSAPP_NUMBER = "923001234567";

Replace 923001234567 with your business's active phone number including the country code (without + or dashes).

2. How to Add or Modify Products

All product data is stored in the data-driven JavaScript array PRODUCTS_DATA. You can add new objects to the list following this schema: 

{
  id: "mbj-013",
  name: "Custom Floral Resin Coaster",
  category: "Custom Gifts",
  price: 1850,
  image: "https://images.unsplash.com/...",
  description: "Hand-poured resin with pressed real flowers.",
  isFreshFlower: false,
  badge: "New Arrival",
  rating: 5.0
}

3. How to Replace Images

You can replace the demo image URLs with direct web URLs or relative image paths (e.g., images/products/jhumky-1.jpg) if hosted in your local repository.

4. How to Deploy on GitHub Pages

  1. Create a GitHub repository named mehakbyjiya.
  2. Upload this file as index.html into the main root folder.
  3. Navigate to Repository Settings > Pages.
  4. Set the Source Branch to main / root and click Save.
  5. Your store will be live in minutes at https://username.github.io/mehakbyjiya.

5. Recommended Multi-File Folder Structure

If you wish to split this single-file setup into modular files later:

/
├── index.html         (Home, Hero, Story, Contact)
├── shop.html          (Catalogue Grid & Search)
├── about.html         (Brand Story & Details)
├── contact.html       (Contact Info & Socials)
├── css/
│   └── style.css      (Custom Styles & Colors)
├── js/
│   ├── products.js    (PRODUCTS_DATA dataset)
│   └── script.js      (Cart, LocalStorage & WhatsApp logic)
└── README.md          (Documentation)
